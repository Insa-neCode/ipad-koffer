Zuständigkeiten, Supabase-Cloud & Automatisierung

Verwalte die 18 Koffer-Patenschaften, Farb-Codes sowie die Echtzeit-Synchronisation für Teams & Smartphones.

1. Echtzeit-Datenbank (Supabase REST API – damit alle denselben Stand sehen)

Trage deine kostenlose Supabase Project URL und den Anon Key ein. Sobald gespeichert, werden alle Meldungen und Paten-Änderungen live über die Tabelle ipad_koffer zwischen allen Smartphones und Microsoft Teams synchronisiert.

SQL-Befehl für Supabase anzeigen (Tabelle & RLS in 30 Sek. anlegen) Aufklappen

Kopiere diesen SQL-Befehl in Supabase unter SQL Editor → New Query und klicke auf Run: 

CREATE TABLE IF NOT EXISTS ipad_koffer (
  id INTEGER PRIMARY KEY,
  room TEXT,
  location TEXT,
  color_name TEXT,
  responsible TEXT,
  email TEXT,
  device_count INTEGER DEFAULT 16,
  status TEXT DEFAULT 'green',
  last_check TIMESTAMPTZ,
  last_reporter TEXT,
  open_issues JSONB DEFAULT '[]'::jsonb,
  history JSONB DEFAULT '[]'::jsonb,
  updated_at TIMESTAMPTZ DEFAULT now()
);

ALTER TABLE ipad_koffer ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Schulweite Koffer-Kontrolle" ON ipad_koffer
  FOR ALL USING (true) WITH CHECK (true);
